## 交易与故障专项

| 场景 | 必需证据 |
| --- | --- |
| 双方同时重发 | PostgreSQL 集成并发测试：只有一笔提交与一组收录，返回同一回执。 |
| 不同申请抢同卡 | 唯一约束触发，全笔回滚；另一方向没有孤立 CollectionEntry。 |
| 事务中断 | 插入第二方向或 outbox 时注入失败，第一方向也回滚；重启可重试。 |
| HTTP 响应丢失 | 服务端已提交后断连接，查询/重放仍返回 committed，不新建交易。 |
| 撤回/解绑/封禁与提交竞争 | 一致锁顺序、终态和当前资格检查；每个竞争场景独立测试。 |
| 断网期间改偏好或注销 | 旧 native receipt 不能绕过新政策；本地记录保留失败原因。 |
| 接收者已有其他版本 | 按 cardId 去重，无新增收录；更新快照走显式 update。 |
| 缓存或事件丢失 | PostgreSQL 回退正确；页面重新读取终态；无空成功掩盖故障。 |
| 媒体生成失败 | 暂存/失败对象不公开；已提交交换不因缩略图失败重复提交。 |
| 房间成员退出/新加入 | 旧 batch 不自动授权新成员；快照版本改变要求重新确认。 |
| 收藏显式更新 | acquiredRevisionId/时间/回执不变，displayRevisionId 显式变更；旧原始媒体仍有引用，隐藏/解绑新版本不可读取。 |
| 不同授权来源撤销 | 关闭 autoAccept 只撤销未提交自动同意；修改 silent/quickGroup 不使 manual receipt 失效；commit 竞争有确定终态。 |
| 已有旧交换 FK 的解绑 | 旧 pending/accepted/cancelled 历史记录存在时，迁移后解绑/注销成功且原始归属事实保留；回退不会重建危险外键。 |
| 锁定/申诉/认领截止 | 计时起点、申诉暂停、当前 claim epoch、截止前提交待审及截止后证明认领分别验证，不能沿用三天 guest purge 误删。 |
| native 恢复 | 设备锁屏、重启、进程死亡、拒绝权限各留实际设备日志和观察结果。 |

## 近场交互与权限专项

这些是 E6/E7 的未来设备验收，官方 API 查证与 UI mock 不能标为已通过。

| 场景 | 必需证据 |
| --- | --- |
| 首次蓝牙授权 | 清洁安装 iOS/Android，只有主动启用近场才请求新增权限；记录 usage 文案和真实系统弹窗，拒绝后不循环申请，保留选卡。 |
| 已授权使用与网络操作 | 三个平台对及跨端两种角色，记录完整步骤；不加入同一 Wi-Fi、不切热点、不进入系统配对设置仍可 BLE 握手；检测 GATT 是否意外触发配对弹窗。 |
| 角色/权限/蓝牙不可用 | native capability 和 OS 状态一致；不将扫描成功当广播成功；拒绝、撤回、蓝牙关闭与硬件缺失分别提示，QR/线上替代明确需要网络。 |
| 多人、同名与误选 | 实际多人/同名设备及遮挡/握持变化；RSSI 不自动批准或选账号；共同验证码对应认证会话、nonce 和确切名单，不泄露未授权身份。 |
| 页面与进程生命周期 | 取消/退出页面/切后台后发现与临时连接停止或暂停，恢复重新验权；已完成/待同步 receipt 不丢失，不隐式启动静默模式。 |
| 移动网络与断网 | 各自移动数据/不同 Wi-Fi/无同一局域网均可会面；无网络且有效预发凭据时仅保存双授权待同步，无凭据则草稿，服务器 committed 才报完成。 |
| 替代方案边界 | NFC iPhone reader/Android HCE 单独记录角色、APDU 和扫描 UI；Nearby 的额外权限/SDK 与 Wi-Fi Aware 初次配对另验收，不自动加入口。 |
| iOS 26 后台会话 | Live Activity 启动/可见/结束及 CBManager 生命周期、Android 发现、锁屏/进程终止各有实机记录；不拿新路径覆盖旧模式限制，不推导重启常驻。 |
| 量测与发布声明 | 每个支持组合记录机型、OS/App/协议、双方角色、发现/握手/提交延迟、误选和失败分类；厘米级/顶部接触等未经验证的说法不能进入产品文案。 |

## 施工前置与兼容专项

| 施工风险 | 必须补充的未来证据 |
| --- | --- |
| 旧客户端与新版页模型 | 旧 strict 响应 raw JSON 未加字段/enum/null back；新版路径支持 optional back/pages；旧写入口安全桥接或明确升级结果。 |
| 已排队媒体清理 | 替图、owner delete、guest TTL、对象补偿共用引用/GC object 行锁与 generation fence；覆盖新引用与 deleting CAS 竞争、旧任务重放和删除结果不明，不能删除 acquired/display/grant/申诉所需对象。 |
| 迁移与恢复 | 新库/升级库/backfill 重跑/并发编辑；旧 accepted 不自动入册；fixture/catalog 和业务数据断言分别执行，真实 PostgreSQL 不跳过。 |
| 新媒体 facade | owner/revision/collection/grant 使用各自 API-owned 白名单；外域和伪造路径不携带 bearer；refresh、取消、切账号和 Blob URL 释放可观察。 |
| 注销新能力 | 真实二次验证/注销入口、账号冻结及跨域生命周期事务/恢复；C05/C11/C12 在启用前接撤销 fence，旧 FK 不阻止解绑。 |
| 新 outbox | eventId/lease/retry/consumer 去重/死信回读；worker crash/重复投递不重复入册，通知失败不改变 committed。 |
| BLE 分批 | C10a 真机角色/权限证据、C10b 联网会面、C11 离线双签/补交分开报告；图片缺缓存时可占位，GATT 分片/重传/取消有边界。 |
| 首个交付 | C00 至 C06 两账号完成上传、审核、收录及名片册；隐藏/解绑/封禁和图片引用竞争通过，favorites 及现有 Dialog/反应继续回归。 |
